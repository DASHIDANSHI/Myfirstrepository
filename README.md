# 目的ランチャー (IntentLauncher)

スマホの使いすぎを防ぐための Android ホームランチャーです。
アプリを開く前に「**今、何をしたいですか？**」と目的をたずね、
その目的に割り当てたアプリだけを表示します。

## コンセプト

- ホーム画面をこのランチャーに置き換えます。
- ホームに戻るたびに、まず「目的」を選びます（連絡する／調べる／移動する…）。
- 目的を選ぶと、その目的に割り当てたアプリだけが並びます。
- **ランチャーに戻るたびに目的はリセット**されるので、毎回「何をしたいか」を意識してからアプリを開くことになります。これが衝動的な使いすぎを抑える仕組みです。
- 目的には任意で自由メモを添えられます（例:「上司に返信する」）。

## 主な画面

| 画面 | 役割 |
| --- | --- |
| 目的選択 (`GoalScreen`) | 「今、何をしたいですか？」＋目的カード一覧＋メモ欄 |
| アプリ一覧 (`AppListScreen`) | 選んだ目的に割り当てられたアプリだけを表示・起動 |
| 設定 (`SettingsScreen`) | 目的の追加・削除、各目的へのアプリ割り当て |

## 技術スタック

- Kotlin + Jetpack Compose (Material 3)
- DataStore Preferences + kotlinx.serialization（目的とアプリ割り当ての保存）
- `PackageManager` でインストール済みアプリを取得・起動
- minSdk 26 / targetSdk 34 / compileSdk 34

## ビルド方法

Android SDK が必要です（Android Studio 推奨）。

```bash
# 環境変数または local.properties で Android SDK の場所を指定
echo "sdk.dir=/path/to/Android/sdk" > local.properties

./gradlew assembleDebug
# 生成物: app/build/outputs/apk/debug/app-debug.apk
```

Android Studio で開く場合は、このリポジトリのルートを開けばそのまま実行できます。

## デフォルトのランチャーに設定する

1. 端末にインストール（`./gradlew installDebug` など）。
2. 端末の「設定 → アプリ → 標準アプリ → ホームアプリ」で「目的ランチャー」を選択。
3. ホームボタンを押すと目的選択画面が表示されます。

## 使い方

1. 初回はデフォルトの目的（連絡する／調べる/…）が入っています。
2. 右上の歯車（設定）から、各目的に起動を許可するアプリを割り当てます。
3. ホームで目的を選ぶ → その目的のアプリだけが表示され、そこから起動します。

## 権限について

- `QUERY_ALL_PACKAGES`: インストール済みアプリを一覧して目的に割り当てるために使用します。個人利用・サイドロード前提の権限で、Google Play で配布する場合はポリシー対応が別途必要です。
