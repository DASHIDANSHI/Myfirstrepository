# FIFA ワールドカップ2026 選手名鑑 / World Cup 2026 Player Almanac

2026 FIFA ワールドカップ（アメリカ・カナダ・メキシコ共催, 6/11〜7/19）の
**出場48カ国・選手名鑑**です。英語表記＋日本語併記で、所属チーム・代表歴・
スタッツ・特徴を1枚のHTMLでブラウズできます。

4. 1〜2分後、下記URLで公開されます（`.nojekyll` 済みなので `data.js` もそのまま配信）

```
https://dashidanshi.github.io/Myfirstrepository/
```

> メインに反映したい場合は、このブランチを `main` にマージしてから Branch に `main` を選んでください。

## 使い方（ローカル）

`index.html` をブラウザで開くだけ（サーバー不要・オフライン動作）。

- 🔍 **検索**: 選手名・所属クラブ・国名で横断検索（英/日どちらでもOK）
- **フィルタ**: 大陸連盟 / グループ / ポジション（GK・DF・MF・FW）
- **並び替え**: 背番号 / 代表キャップ / 代表ゴール / 年齢
- 国名の見出しをクリックで開閉。右上「すべて展開/折りたたみ」で一括切替

## ファイル構成

| ファイル | 役割 |

## データを追記・修正する

`data.js` の各チームの `players: []` に下記フォーマットで追加してください。

```js
{
  number: 7, pos: "MF",                 // GK | DF | MF | FW
  name_en: "Takefusa Kubo", name_jp: "久保 建英 (くぼ たけふさ)",
  club_en: "Real Sociedad", club_jp: "レアル・ソシエダ",
  age: 24, caps: 40, goals: 6,          // 数値（不明は null でOK → "—"表示）
  height_cm: 173, foot: "左",            // 右 | 左 | 両
  traits: "右サイドの主役。緩急のドリブルと左足、ラストパス。"  // 特徴(日本語)
}
```

選手未登録の国（南アフリカ・ハイチ・キュラソー・カーボベルデ等）は
プレースホルダ表示になります。同じ形式で `players` に追記すれば反映されます。

## ⚠️ データの信頼度について

招集メンバー・スタッツは **各協会発表（2026年5月）および2026年1月時点の
公開情報に基づく best-effort** です。数値（キャップ数・ゴール・年齢等）は
概算を含みます。正式記録での上書きを推奨します。日本代表は26名フル登録、
その他は主力選手を中心に収録しています。
