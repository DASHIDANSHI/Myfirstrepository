# 研修英語トレーナー

2026年11月2日〜4日の社内英語研修(アジア太平洋9カ国・約50人)に向けて、
研修と懇親会で使う英語フレーズを間隔反復(SRS)で覚えるための学習ツール。

設計の背景と根拠は [DESIGN.md](DESIGN.md) を参照。

## 使い方

`index.html` をブラウザで開くだけ。インストールもサーバーも不要。

```
git clone <このリポジトリ>
cd Myfirstrepository
open index.html          # macOS / Windows は start index.html
```

スマホで使う場合は GitHub Pages などに置いて開く(`index.html` と `sentences.js` の2ファイルだけで動く)。

## 毎日やること(15〜20分)

1. 「学習」タブを開く
2. 日本語を見て、英語を **声に出して** 言う
3. 「答えを見る」→ 自動で音声が流れる → **3回音読**
4. 「わからなかった / 微妙 / できた」で自己評価

評価に応じて次に出てくる日が変わる(ライトナー方式)。

| Box | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 次回まで | 当日 | 1日 | 3日 | 7日 | 14日 | 30日 |

Box 5 で2回連続「できた」→ 習得済み。

## 画面

| タブ | 用途 |
|---|---|
| **学習** | 今日の復習+新規10文。集中モード(カテゴリ・場面を指定した練習)もここから |
| **文章一覧** | 全文章の検索・追加・編集・削除。聞き取れなかった表現をその場で登録 |
| **チートシート** | カテゴリ別フレーズ一覧+文化メモ。印刷して研修当日に持ち込む用 |
| **進捗** | 研修までのカウントダウン、連続日数、カテゴリ別の定着率、バックアップ |

## 収録フレーズ(405文)

| カテゴリ | 文数 | 重要度 |
|---|---|---|
| 聞き返し・確認 | 45 | ★★★ |
| 自己紹介・名前 | 45 | ★★★ |
| 質問・依頼 | 35 | ★★ |
| 意見・賛成・反対 | 50 | ★★★ |
| 提案・役割分担 | 45 | ★★★ |
| 懇親会・パーティ | 70 | ★★★ |
| 雑談・文化の話題 | 40 | ★★ |
| 進捗報告・発表 | 40 | ★★ |
| 会議進行・トラブル | 35 | ★ |

懇親会は3日間の流れ(輪に入る → 乾杯 → 飲まない選択 → 相手を知る → 盛り上げる →
連絡先交換 → 切り上げる → 翌朝の再会 → 最終日の別れ)を場面タグで練習できる。

## 文章を足す

**アプリから**: 「文章一覧」タブの入力欄に英語・日本語・カテゴリを入れて「追加」。
翌日から復習に出てくる。

**まとめて足す**: `sentences.js` の `RAW` の各カテゴリ配列の **末尾** に追記する。

```js
["Could you break that down for me?", "もう少し噛み砕いて説明してもらえますか?", ["discussion"]],
```

> 配列の途中に挿入すると以降の id がずれ、学習進捗のひもづけが変わってしまう。追加は末尾に。

## バックアップ

学習データはブラウザの localStorage にだけ保存される。履歴削除や機種変更で消えるので、
**週に一度は「進捗」タブから JSON を書き出しておくこと**。同じ画面から読み込みで復元できる。

## 音声について

Web Speech API を使い、端末にある英語音声(en-AU / en-NZ / en-IN / en-GB / en-US)を
ランダムに切り替えて再生する。参加者の英語は発音の幅が広いため、同じ文を違う音・違う速度
(0.7x / 1.0x / 1.2x)で聞いて耳を慣らす狙い。

中国・韓国・インドネシア訛りの英語は音声合成では再現できない。補い方はチートシート末尾の
「聞き取りの備え」に記載。
